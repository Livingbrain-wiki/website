05 · Coding agents

Every agent starts with the company's memory.

Connect Claude Code, Codex, Cursor, OpenCode or any agent that supports MCP. Before an agent writes code, it asks the brain for team conventions, past decisions, who owns what, and what was tried and failed.

Agents → brain opt-in

The prompts your team runs and the decisions agents make along the way ("we switched to Postgres because…", "this module is fragile") become wiki pages that link to the session they came from. Secrets are redacted before anything is stored.

Brain → agents

Before an agent writes code, it asks for context: conventions, past decisions, owners, and what was tried and failed. Every agent on the team starts with the company's memory instead of a blank slate.

10 · FAQ

Questions

Is my data used for training?

+

No. Your workspace's messages and pages are never used to train models, ours or anyone else's. If you bring your own model, requests go to your provider under your account's terms.

Can I self-host?

+

You can export the whole brain as Markdown at any time and point it at a self-hosted model through any OpenAI-compatible endpoint. A fully self-hosted runtime is something we're exploring. Tell us on the waitlist if you need it.

Which models?

+

Crew includes our default model. On Bring your own model, connect Anthropic, OpenAI, OpenRouter or any OpenAI-compatible endpoint, including self-hosted ones.

What does "living" mean?

+

Most wikis start going stale the day they're written. Living Brain revisits its own pages on a schedule: it merges duplicates, flags contradictions, retires facts that are no longer true and rewrites summaries. It also learns how each person works, so its answers improve every week.

How is it different from Slack AI or Glean?

+

Search tools find what already exists. Living Brain writes and maintains a wiki you own as Markdown, cites the message behind every fact, acts in your tools, gives your coding agents the same memory, and is priced per workspace instead of per seat.

Which coding agents can I connect?

+

Any agent that supports MCP, including Claude Code, Codex, Cursor and OpenCode. We're not affiliated with these tools; they connect through the open protocol.

Do you store my agent prompts and code?

+

Only if you opt in. Prompts and session notes are stored with secrets redacted first. Source code is never stored unless you allow it.
