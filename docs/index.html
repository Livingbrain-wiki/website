Docs · Early access

Guides and reference.

Start with the guides to sign in, set up a workspace and connect the Mac app. The reference pages describe each part in detail. Living Brain is open in early access at app.livingbrain.wiki; anything marked planned on the site is not built yet.

Guides

  • Getting started

    Sign in, set up your workspace, then connect the CLI or the Mac app. The web app needs no install.

  • Workspaces and members

    What a workspace holds, who may do what (owner, admin, member, viewer), and how people join.

  • Imports

    Bring Markdown notes, folders, and ChatGPT or Claude exports into a personal or shared brain. Nothing uploads until you confirm.

  • Coding-agent sync and transcripts

    How your Claude Code and Codex sessions reach the brain, what is sent and what never leaves your Mac, and how the compiled wiki reads them.

  • The GitHub App

    Connect repositories so their commits, issues and pull requests are read into the brain, with a backfill that runs on the server.

  • Facts and dreaming

    How the brain keeps dated facts, shows which are still confirmed, and tidies old ones in a background pass that keeps the history.

  • Access, agents and audit

    Who can read what, how agent accounts get their own limited keys, and how owners and admins see every change to settings and access.

  • Connect a coding agent over MCP

    Point an MCP client at the Living Brain endpoint, sign in with a token, and use the five tools it offers.

  • Import your ChatGPT history

    Export your ChatGPT history from ChatGPT, then import it with the livingbrain CLI. The preview comes first; nothing uploads until you confirm.

Reference

Reference pages are copies of the product repository's documentation, pinned to commit 7163b59. The source is on GitHub.

  • Coding-agent sessions

    How synced coding-agent sessions become a compiled wiki: queue, compiler, schedule and transcripts.

  • Agent logs

    The livingbrain logs commands: what is read, what is redacted, and what is sent when you opt in.

  • Import

    livingbrain import: Markdown folders, ChatGPT and Claude exports, previews, exclusions and redaction.

  • MCP

    The MCP endpoint: its five tools, how every read is scoped to the person asking, and citations.

  • GitHub connection

    The GitHub App: which events and records come in, how the backfill runs, and what is stored.

  • Temporal facts

    Facts with dates: supersession, freshness, reconciliation and dreaming, and the read API.

  • Brain jobs on your subscription

    Let your own Claude Code or Codex answer brain jobs on your Mac, with tools off and a read-only sandbox.

  • Telemetry

    What the CLI and a self-hosted server may send as anonymous usage counts, the live map, and the OpenTelemetry export.

  • Anonymous usage data

    The counted batch the CLI and self-hosted servers may send, field by field, and what is never in it.
