Integrations

Planned

Works with the tools you already use.

Everything on this page is planned. Other companies' names and logos only say what Living Brain is planned to work with; we're not affiliated with them.

Code

Where the work happens.

    • GitHub
    The Living Brain GitHub App keeps the wiki in your own git repo and proposes every change as a pull request. You own it
    • Claude Code
    • Codex
    • Hermes
    • Cursor
    • OpenCode
    • Claude Desktop
    Any harness that supports MCP. Coding harnesses
    • Linear
    • Notion
    The brain acts in them through their MCP servers, with each person's own connection.
  • API and SDKsAn open REST API with webhooks, and SDKs for TypeScript, Python and Rust, so you can build your own tools on the brain.planned
  • White-label appThe app under your own name, logo and domain, installable on phone and desktop.planned

Chat

Where people ask.

    • Slack
    Invite it to channels. It answers in the thread, with the asker's own access.
    • Discord
    Answers in threads, with a /brain ask slash command. Role-gated channels map to permissions, so it only answers with what the asker's roles can see.
    • WhatsApp
    • Telegram
    laterAfter Slack and Discord.

Mail

Forward what matters, or connect a mailbox.

  • Owlpost brain inboxsimplestForward, BCC or auto-forward mail to your brain's own address on Owlpost, our sister email service. No mailbox access needed.
    • Gmail
    • Outlook
    • Microsoft 365
    • IMAP
    Connect a whole mailbox and calendar, read-only. It stays in your personal memory. How mail stays private

Imports

Bring your history.

    • ChatGPT
    Import your export with the livingbrain CLI, on your machine. Step-by-step guide
    • Claude
    Claude exports import the same way.

Monitoring and logs

Read-only, so it knows when prod is down.

    • Grafana
    Answers "is prod down?" with the current numbers and a link to the exact panel.
    • Loki
    • Elasticsearch
    • Datadog
    • CloudWatch
    • Cloudflare
    • Sentry
    Reads your logs and says what changed: when the errors started and which deploy came before.
  • OpenTelemetryExports its own metrics, traces and logs, so you can watch it in Grafana, Datadog or Honeycomb.

Models

Bring your own LLM, on every plan.

    • Anthropic
    • OpenAI
    • OpenRouter
    • LiteLLM
    Or any OpenAI-compatible endpoint, including self-hosted ones. Choose a model per role.
    • DeepSeek
    Crew includes $5 of DeepSeek credit each month. Pricing
