Skills · Agents

Set up Living Brain with your agent.

The livingbrain-setup skill takes an agent through setting up Living Brain for a team: the workspace, the CLI, GitHub per organisation, Mac session sync, MCP for Claude Code, Codex and Claude connectors, imports and invites. It says which steps the agent runs, and which ones a person clicks.

Skill
livingbrain-setup
Files
SKILL.md and reference.md
Format
Plain Markdown. Installs as a Claude Code skill.
Needs
A Living Brain account. An owner or admin for GitHub.

Early access · Follows the live app

Install it

Pick one. Both put the same two files in place. Start a new Claude Code session after you install.

For you, in every project

mkdir -p ~/.claude/skills/livingbrain-setup && \
curl -fsSL https://livingbrain.wiki/skills/livingbrain-setup/SKILL.md -o ~/.claude/skills/livingbrain-setup/SKILL.md && \
curl -fsSL https://livingbrain.wiki/skills/livingbrain-setup/reference.md -o ~/.claude/skills/livingbrain-setup/reference.md

For one repository

Run this from the repository's root. It commits nothing: add the folder to git if your team should share it.

mkdir -p .claude/skills/livingbrain-setup && \
curl -fsSL https://livingbrain.wiki/skills/livingbrain-setup/SKILL.md -o .claude/skills/livingbrain-setup/SKILL.md && \
curl -fsSL https://livingbrain.wiki/skills/livingbrain-setup/reference.md -o .claude/skills/livingbrain-setup/reference.md

Then ask your agent

“Set up Living Brain for our team.”

The agent asks for the company's name, the GitHub organisations and the people to invite. Then it works through the steps below, and stops where a person has to click.

What it covers

  1. Preflight. Agent. Company, workspace, GitHub organisations, Mac users, imports, invites.
  2. Choose the workspace. You. One company, one workspace. Never two companies in one.
  3. Install the CLI. You, then agent. From the Mac app, or from a checkout.
  4. Sign the CLI in. Agent starts, you approve in the browser for the right workspace.
  5. Connect GitHub. You install the Living Brain GitHub App, as an owner or admin, per organisation. The agent checks the projects.
  6. Sync Mac sessions. You install and opt in each repository. The agent verifies with a dry run.
  7. Connect MCP. Agent for Claude Code and Codex. You for a Claude connector.
  8. Import. Agent runs the import. You answer its upload prompt.
  9. Invite people. You, with Member, Admin or Owner.
  10. Verify and troubleshoot. Agent. A table of the real error messages, and what to do for each.

Rules it follows

  • No secrets in chat. Tokens stay in the keychain or in an environment variable. The agent never prints one.
  • No deletes, no hand backfills. Agents have no delete tools. GitHub history and compiles run in the cron, not by script.
  • You answer the prompts that send data. An import asks before it uploads, and only you say yes.

Coming soon

Routing one repository's sessions to a chosen workspace is coming soon. Until it ships, sign the CLI in to the workspace you want before you sync.
